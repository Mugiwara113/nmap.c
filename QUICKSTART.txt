🚀 GETTING STARTED:

1. EXTRACT THE ARCHIVE:

   On macOS/Linux:
   $ tar -xzf nmap_c.tar.gz
   $ cd nmap_c

   On Windows (using 7-Zip, WinRAR, or built-in):
   Extract nmap_c.zip to a folder

2. BUILD FROM SOURCE (if needed):

   macOS/Linux:
   $ make clean
   $ make

   Windows (MinGW):
   $ gcc -o nmap_c.exe main.c scanner.c -lws2_32

   Windows (MSVC):
   $ cl main.c scanner.c ws2_32.lib

3. RUN THE SCANNER:

   macOS/Linux:
   $ ./nmap_c [target] [options]

   Windows:
   > nmap_c.exe [target] [options]

═══════════════════════════════════════════════════════════════════

📋 USAGE EXAMPLES:

Basic scan (ports 1-1000):
$ ./nmap_c google.com

Full port scan (1-65535):
$ ./nmap_c 192.168.1.1 -p 1-65535

Custom threads and timeout:
$ ./nmap_c example.com -p 1-10000 -t 128 -T 5

Scan localhost:
$ ./nmap_c localhost -p 1-1024

Show help:
$ ./nmap_c -h

═══════════════════════════════════════════════════════════════════

🔧 OPTIONS:

-p <start>[-<end>]     Port range to scan (default: 1-1000)
-t <threads>           Number of threads (default: 64)
                       (higher = faster, max 256)
-T <timeout>           Connection timeout in seconds (default: 3)
                       (increase for slow networks)
-h                     Show help message

🎯 PERFORMANCE TIPS:

• For FAST SCANNING: Increase threads
  $ ./nmap_c target -t 256

• For SLOW NETWORKS: Increase timeout
  $ ./nmap_c target -T 10

• For QUICK TESTS: Reduce port range
  $ ./nmap_c target -p 1-1024

• For FULL SCAN: Use all options
  $ ./nmap_c target -p 1-65535 -t 256 -T 5

🛠️ TROUBLESHOOTING:

Q: "Connection refused" on many ports
A: This is normal! It means ports are closed.

Q: Scan is too slow
A: Try: ./nmap_c target -t 256 -T 1

Q: Port shows "FILTERED"
A: Usually means a firewall is blocking the port

Q: Build fails on Windows
A: Make sure you have MinGW or MSVC installed
   Or use the pre-compiled nmap_c binary on macOS/Linux
